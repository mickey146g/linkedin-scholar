# LinkedIn Scholar

Michael Appiah-Kubi's LinkedIn posts, ranked like papers: reactions in place of citations, with a reaction h-index, i10-index and monthly impressions.

Live page: https://mickey146g.github.io/linkedin-scholar/

- `index.html` is the published page (built from `template.html` + `data.json`).
- `data.json` holds the numbers. Update it monthly from LinkedIn's Manage content tab and creator analytics, then rebuild `index.html` by replacing `__DATA__` in `template.html` with the JSON.

Not affiliated with LinkedIn or Google.
